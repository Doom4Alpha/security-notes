## How entries are written
Each file covers one course, room, or lab session: what it covered, what I did hands-on, what was confusing, what clicked. Lab/challenge findings are written up briefly like a mini incident note — what happened, how I found it, what I'd recommend — practicing the reporting side of SOC work, not just the technical side.

**Note:** entries reflect my own understanding and process, not step-by-step solutions to platform exercises.
